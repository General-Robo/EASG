Retained warm-grey matte-silicone workmat appearance (no longer the default).

Approved reference: output/asset_previews/workmat_visual_20261015/02_warm_grey
These are the exact procedural textures from that preview, copied into Asset
so runtime rendering does not depend on temporary files or preview outputs.

color.png: sRGB, nominal RGB (144, 136, 122), subtle grain/colour variation.
roughness.png: linear data, nominal roughness 0.74 with subtle variation.
normal.png: tangent-space normal, linear data, shading-only microtexture.
All maps: 2048 x 2048. Non-metallic surface.

Geometry is generated by script/construct_scene/workmat_appearance.py:
12 mm plan-view corner radius and 2 mm edge bevel at the default 20 mm thickness.
WorkMat is a transform with a Collider child (the original box dimensions) and
a Visual child (rounded render-only mesh). The physics material stays on the
parent and is inherited by Collider. Visual geometry has no collision API.
Friction, compliant contact and other physics parameters are unchanged.
