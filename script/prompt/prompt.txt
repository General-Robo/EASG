TCP coordinate frame:
The TCP-centered coordinate frame has its origin at the tool center point (TCP). The X and Y axes are shown in the image. The XY plane is parallel to the wrist-camera image plane, and the Z axis is perpendicular to it. +Z points into the image, away from the camera and toward the scene; -Z points out of the image, toward the camera. These are 3D depth directions, not upward or downward directions in the 2D image. +Z points into the observed scene, while -Z points outward, away from the observed scene.

Z-axis distance information:
The Z-axis distance is the signed Z coordinate, in the TCP-centered frame, of the intersection between the Z axis through the TCP origin and a surface visible in the current wrist-camera observation. This intersection is marked in the image as the endpoint of the drawn Z-axis segment. If it lies on the positive Z half-axis, only the positive segment is drawn; if it lies on the negative Z half-axis, only the negative segment is drawn.

A smaller signed value means the intersection is closer to the camera image plane; a larger signed value means it is farther from that plane. A larger absolute value means the intersection is farther from the TCP, while a smaller absolute value means it is closer to the TCP. A value of zero means an object's surface is exactly at the TCP.

Field definitions:
- task_state indicates whether the task is complete. Use 0 when the task is incomplete and another robot action is needed. Use 1 when the task is already complete in the current image.
- Use 'dx,dy,dz,distance_cm' to represent translation. Translation is a relative displacement in the TCP-centered coordinate frame. dx,dy,dz is a 3D unit vector expressed in the TCP-centered coordinate frame shown in the processed wrist image. distance_cm is the translation distance in centimeters. The displacement in this frame is distance_cm × (dx,dy,dz). For example, +0.00,+0.00,+1.00,+2.00 means moving 2 cm along the current TCP +Z axis. distance_cm must satisfy 0 <= distance_cm <= 6 for every action. This is the total 3D displacement magnitude, not a per-axis limit. If the target is farther away, move at most 6 cm toward it in one action and reassess in the next observation. If no translation is needed, set dx,dy,dz to +0.00,+0.00,+0.00 and distance_cm to +0.00.
- Rotation uses axis–angle representation, ax,ay,az specifies a unit rotation axis passing through the TCP origin, expressed in the TCP frame of the current observation. angle_deg specifies a rotation about this axis using the right-hand rule. If no rotation is needed, set ax,ay,az to +0.00,+0.00,+1.00 and angle_deg to +0.00.
- gripper_state is continuous: 0.0 means fully closed, and 1.0 means fully open.
